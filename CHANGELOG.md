# Changelog

## 0.3.0 — 2026-10-29 (development)

- Reuse available caption URLs and add an isolated alternative extractor.
- Enriched timestamped TXT/JSON and a stable, versioned library.
- Separate video, audio, transcription, export and format-inspection jobs.
- Reuse local media for audio, preserve source codecs and support MP3 conversion.
- Native AppKit/WKWebView shell, original icon, menus, optional notifications and explicit lifecycle controls.
- Local settings, optional idle-sleep prevention and actual stage/transfer progress.
- Independent source-scoped oracles, hybrid/hierarchical retrieval, checkpointed textual audits and local cited generation.
- Separate sandbox licensing ledger with idempotency, expiration, revocation and signed claims.
- Source-only public export, dependency evidence and collaboration/release scaffolding.

This is a development release. Distribution signing/notarization, clean-machine validation, platform permissions and provider sandbox homologation remain separate gates. No personal library or private Git history is part of this repository.

## Manual interface revision

- Compact per-channel controls, individual/collective metadata refresh and verified file ratios.
- Current and overall progress, measured storage and approximate remaining text space/time.
- Default/per-channel TXT destinations, standalone copies, native folder picker and Finder action.
- Available-file totals and weekly/monthly counts without duplicate attempts or copies.
- Neutral blue/graphite day, night and system themes; Downloads first.
- Public Instagram collection and temporary local audio transcription; optional native login for protected content.
- Incremental task planning during discovery and acknowledged Instagram iterator checkpoints.

- Three simultaneous channel acquisition/transcription slots, fair channel rotation and independent local publication.
- Atomic per-channel reservations, persisted scheduling turns and supervision of every parallel worker.

- New channel registrations enter a persistent paused queue; explicit release starts them without affecting active channels.
- Separate paused section, chronological queue order, preserved folder creation and independent pause/resume controls.

- Recurring channel workspace with persisted discovery comparisons, New tab, platform marks/groups, search and state filters.
- Symbol controls with immediate busy feedback and lightweight pause acknowledgement; transactional quick pause/resume recovery.
- Collective Start all/selected with independent per-channel results and existing-file skipping.
- Completion-month TXT folders and MP3/MP4 shortcuts, preserving original objects and edited text.
- Dedicated download manager with queue/completed tabs, simpler link/format entry and immediate per-row controls.
