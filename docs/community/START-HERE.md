# Comece por aqui / Start here

Escolha uma tarefa de acordo com seu equipamento e interesse. Você pode ajudar testando e descrevendo resultados, sem escrever código. Os relatos devem usar somente fontes fictícias ou uma instalação de teste autorizada; nunca anexe seu acervo.

| Tarefa | Perfil | Primeira entrega útil |
|---|---|---|
| Validar Windows/WSL em um PC limpo | Pessoa com Windows | Relatório reproduzível de instalação, abertura e retomada |
| Auditar navegação por teclado | Pessoa interessada em acessibilidade | Passos para uma barreira real e uma correção pequena |
| Revisar o guia em inglês | Pessoa que lê português e inglês | Ajustes de clareza e consistência dos termos |
| Ampliar teste de interrupção e retomada | Desenvolvimento Python | Um teste isolado que prove preservação e não duplicação |
| Simplificar a primeira instalação Mac | Desenvolvimento macOS | Diagnóstico da instalação limpa e uma melhoria delimitada |

Cada issue tem contexto, arquivos de referência e critérios de conclusão. Confira a [lista de tarefas abertas](../../../../issues) antes de começar para combinar o escopo e evitar trabalho duplicado.

**English:** these tasks welcome installation testers, accessibility reviewers, translators and developers. Read [CONTRIBUTING.md](../../CONTRIBUTING.md), coordinate scope in the matching issue and use synthetic data only. The current Windows edition is a WSL preview; a native Windows application remains roadmap work.
