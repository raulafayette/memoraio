# Code of conduct

Treat contributors with respect. Welcome different backgrounds and skill levels. Discuss concrete behavior and evidence; avoid harassment, discrimination, personal attacks, doxxing and sharing private data.

Maintainers may remove harmful material, restrict participation or ask for a correction. Report sensitive incidents using the repository's private reporting channel when available; do not publish personal details in an issue. If no private channel exists, contact an identified maintainer through a channel they publicly provide.

Apply the same standards to issues, pull requests, code review, documentation and other project spaces. Good-faith disagreement is welcome; abuse is not.
